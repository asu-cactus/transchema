3. AgentFlow pipeline granularity — run_agentflow_pipeline.sh
================================================================
Results are written to timestamped dirs under AgentFlow/results/:

  AgentFlow/results/overnight_af_pipeline_l1_0_50_{timestamp}/
  AgentFlow/results/overnight_af_pipeline_l1_51_100_{timestamp}/
  AgentFlow/results/overnight_af_pipeline_l4_15_57_{timestamp}/
  AgentFlow/results/overnight_af_pipeline_l4_58_100_{timestamp}/
  AgentFlow/results/overnight_af_pipeline_l9_0_50_{timestamp}/
  AgentFlow/results/overnight_af_pipeline_l9_51_100_{timestamp}/

Inside each dir:
  results_summary.csv        ← main file for analysis
  case_{id}/
    {id}_result.txt          ← human-readable per-case summary
    {id}_full_output.json    ← full solver output
    logs/
      agentflow_all_*.log    ← complete trace
      agentflow_prompts_*.log
      agentflow_tools_*.log

Raw stdout:
  logs_agentflow_pipeline/af_pipeline_l{N}_*.log

Key columns in results_summary.csv:
  case_id, is_correct, score, score_fd, column_mapping_score,
  average_similarity, latency_seconds, cost
